Detection Info
Algorithm
Butterworth Low-pass Filter (20Hz cutoff) removes sensor jitter.
Sliding Window (2.56s, 50% overlap) captures temporal patterns.
SMA + Gravity Vector separation identifies tilt vs. movement.
Rule-based Classifier maps feature vectors to activity states.
